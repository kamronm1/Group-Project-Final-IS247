This project is a Java-based virtual vending machine that realistically simulates the operations of a physical vending machine. Users can browse available items, select a product by entering its slot code, and submit payment to complete a transaction. The system intelligently validates common scenarios—including sold-out items, expired products, and insufficient funds—before dispensing any item. Inventory data is loaded from an external file, enabling easy product updates without altering the codebase. The application demonstrates core object-oriented programming concepts such as inheritance, abstraction, and encapsulation, while also showcasing effective use of file handling, collections, and exception handling.
